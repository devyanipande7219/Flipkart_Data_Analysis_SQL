# 📊 Flipkart Mobiles Data Analysis (SQL Project)

## 📌 Project Overview

This project focuses on **Exploratory Data Analysis (EDA)** of Flipkart mobile data using SQL.
The dataset contains detailed information about different mobile phones such as brand, ratings, reviews, pricing, and discounts.

The objective of this project is to analyze the data and extract useful insights about market trends, pricing strategies, and brand performance.

---

## 🗂️ Dataset Details

* Dataset: Flipkart Mobiles (Excel file)
* Total Records: Multiple mobile listings
* Key Attributes:

  * Product Name
  * Brand
  * Ratings
  * Number of Ratings & Reviews
  * Product Features
  * Selling Price (MSP)
  * Original Price (MRP)
  * Discount Percentage

## 🔍 Analysis Performed

### 🔹 Data Exploration

* Examined overall dataset structure
* Identified unique mobile brands

### 🔹 Discount Analysis

* Filtered mobiles with high discounts
* Identified top discounted products

### 🔹 Brand-wise Analysis

* Compared average ratings across brands
* Analyzed total customer engagement using reviews

### 🔹 Pricing Analysis

* Calculated maximum discount offered by brands
* Compared pricing strategies across different brands

### 🔹 Price Segmentation

* Categorized mobiles into different price ranges:

  * Below ₹10,000
  * ₹10,000 – ₹20,000
  * ₹20,000 – ₹40,000
  * Above ₹40,000

---

## 📈 Key Insights

* Premium brands like **Apple** and **Samsung** dominate the high-price segment
* Brands like **Infinix**, **Lava**, and **Itel** focus on budget-friendly devices
* **Samsung** provides some of the highest discounts among brands
* Mid-range brands such as **Realme** and **Vivo** perform well in ratings and popularity
* High discounts do not always guarantee higher ratings
